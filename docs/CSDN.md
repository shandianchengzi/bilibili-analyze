# 【开源工具】bilibili-analyze｜油猴脚本导出 B 站投稿列表与视频章节

整理一个 UP 主的投稿时，我想拿到的不只是视频链接，还包括标题、简介、封面、时长和发布时间。有时我只想找出没有加入合集的视频，逐条打开、复制再整理就比较麻烦。

于是把这件事做成了一个油猴脚本：在 B 站空间页直接读取公开投稿，先筛选、勾选，再导出 JSON 和 CSV。同一个列表获取一次之后，可以反复选择和导出，不用每次重新抓取。

另外，有些视频自带章节 / 看点。脚本也支持在视频播放页直接拿到这些时间点与标题，复制成文本，或导出结构化文件。

## 一、项目地址与安装

GitHub：https://github.com/shandianchengzi/bilibili-analyze

Greasy Fork：待发布后补充脚本页面地址。

先给浏览器安装 Tampermonkey 或 Violentmonkey，然后安装本项目的 `bilibili_space_video_exporter.user.js`。脚本是单文件，不需要搭建服务或填写 API Key。

发布准备阶段可以在 GitHub 中打开脚本、点击 Raw 安装，或者新建油猴脚本并粘贴完整源码。正式发布后可使用 Greasy Fork 的安装入口。

## 二、功能特点

① **获取公开投稿**：自动识别当前空间 UID，分页获取接口可见的公开投稿，按 BV / AV 号去重。

② **先筛选再导出**：默认显示并选中未加入合集的视频，也可以切换全部投稿、已加入合集，搜索标题或逐条取消勾选。

③ **一次获取，多次导出**：“获取投稿列表”和“选择并导出”分开，整理另一份结果时无需重新请求。

④ **导出视频章节**：按当前视频、当前分 P 读取章节 / 看点，可以复制“时间 标题”，也可以下载 JSON / CSV。

## 三、使用效果

下面两张图片是依据脚本布局制作的功能示意图，使用演示数据，用来说明操作，不是真实网页截图或 UP 主统计。

### 1. 投稿筛选

![投稿筛选界面：演示数据](https://raw.githubusercontent.com/shandianchengzi/bilibili-analyze/main/docs/images/uploads-demo.png)

打开 UP 主空间页面，点击右下角的“获取投稿列表”。读取完成后弹出选择窗口，默认勾选未加入合集的视频。

可以直接取消不需要的视频，也可以搜索标题、切换筛选范围，再使用“全选当前筛选 / 清空当前筛选”。

这里有个操作细节：**切换筛选不会自动清空其他范围里已勾选的视频**。点击导出前，可以看一下底部的“已选”数量，确认导出的范围。

### 2. 视频章节

![视频章节导出界面：演示数据](https://raw.githubusercontent.com/shandianchengzi/bilibili-analyze/main/docs/images/chapters-demo.png)

进入普通 BV 视频播放页，点击“获取章节”。弹窗会显示章节标题、起止时间和图片。

“复制章节文本”得到的是这种形式：

```text
00:00 开场
03:40 第一部分
04:49 第二部分
```

这个例子只是格式示意。脚本读取的是视频本身提供的章节，不会自动听音频、分析字幕或生成章节。

## 四、导出的文件里有什么

投稿导出会同时下载 JSON 和 CSV。

| 内容 | 字段 |
| --- | --- |
| 基本信息 | 标题、简介、视频链接、BV / AV 号、封面 URL |
| 时间信息 | 发布时间、时间戳、视频时长 |
| 投稿属性 | UP 主、UID、分区、版权、合作视频 |
| 统计与合集 | 播放、弹幕、评论、收藏，以及合集状态、ID、名称和数量 |

JSON 还保留 `raw` 原始接口字段，方便后续写脚本分析；CSV 适合直接用表格软件整理。接口没有返回的字段会留空，合集判断也以接口返回的字段为准。

章节导出包括章节序号、标题、开始 / 结束时间与秒数、持续秒数、图片 URL 等。这里导出的是图片地址，不会下载封面图片或视频文件。

## 五、为什么把“获取”和“导出”分开

第一次获取列表之后，我可能只导出其中一部分。过一会儿想换一个筛选条件、再导出另一份，数据其实还在页面里。

所以脚本保留了“选择并导出”按钮：重新打开当前列表，选好再下载。只有点“获取投稿列表”才重新请求 B 站。

缓存目前保存在页面内存中，刷新或关闭页面后就没有了。获取时也不要切换到另一个 UP 主，避免把旧列表当作新空间的结果。

## 六、技术原理

1. 从空间页 URL 读取 UID，从视频 URL 读取 BV 号和分 P。
2. 投稿功能获取 WBI 密钥，使用 CryptoJS MD5 生成请求签名。
3. 分页读取空间公开投稿，规范化字段并去重，然后按合集状态展示选择窗口。
4. 章节功能获取视频详情和 CID，读取播放器信息的 `view_points`。
5. 在浏览器里生成 Blob，由扩展下载接口或浏览器保存为 JSON / CSV。

脚本没有后端。它复用当前浏览器的 B 站登录态发送请求，不向作者上传 Cookie 或导出结果。CryptoJS 从 cdnjs 加载；列表中的预览图片使用 B 站接口返回的地址。

## 七、注意事项

- 请先登录 B 站，等页面加载后再操作。
- 只能获取接口可见的公开投稿，删除、私有、审核中的内容无法导出。
- 分页之间等待 650 ms；遇到 `-352`、`-412` 等风控提示时，停止请求并稍后重试。
- 多 P 视频按当前 URL 的 `?p=N` 获取章节；切换后重新获取。
- 有些视频没有章节 / 看点，返回空结果是正常情况。
- 浏览器可能要求允许连续下载，才能保存投稿的 JSON 和 CSV 两个文件。
- B 站接口或浏览器扩展变化可能影响功能；可在 GitHub Issues 中附版本和报错反馈，不要上传 Cookie。
