# Bilibili 投稿与视频章节导出

把 B 站 UP 主公开投稿整理成 JSON / CSV，筛选未加入合集的视频；在视频播放页一键复制或导出章节 / 看点。

## 功能特点

① **投稿整理**：自动识别空间 UID，分页获取公开投稿，按 BV / AV 号去重。

② **合集筛选**：默认显示并选中“未加入合集”的视频，支持全部投稿、已加入合集、标题搜索和逐条勾选。

③ **重复导出**：获取列表后先预览再导出；“选择并导出”复用当前页面内存中的数据，无需再次抓取。

④ **章节导出**：读取当前视频、当前分 P 的章节 / 看点，支持复制时间与标题、导出 JSON / CSV。

⑤ **保留来源**：JSON 保留原始接口字段，CSV 便于用 Excel 或其他工具继续整理。

## 使用方法

### 导出 UP 主投稿

打开 `https://space.bilibili.com/<UID>/upload/video`，在右下角点击“获取投稿列表”。

读取完成后弹出选择窗口。默认筛选并选中全部未加入合集的条目；可搜索标题、切换筛选、全选或清空当前筛选、逐条取消勾选。**切换筛选或搜索不会自动清除其他筛选中已经勾选的视频**，请核对“已选”数量。

点击“导出已选视频”下载 JSON 和 CSV。之后点击面板中的“选择并导出”，即可重新选择并导出当前数据。只有点击“获取投稿列表”才会重新请求。缓存仅存在当前页面内存中，刷新页面后需要重新获取。

### 导出视频章节 / 看点

打开 `https://www.bilibili.com/video/<BV号>`，点击“获取章节”，然后复制章节文本或分别导出 JSON / CSV。点击“再次查看”可重新打开已经读取的章节。

多 P 视频按当前 URL 的 `?p=N` 读取对应 CID；切换分 P 后重新获取。当前功能读取播放器返回的 `view_points`，不会从音频、字幕或评论自动生成章节。视频未提供章节时会提示空结果。

## 导出内容

| 类型 | 主要字段 |
| --- | --- |
| 投稿 | 标题、BV/AV 号、链接、封面 URL、发布时间及时间戳、时长、简介、播放/弹幕/评论/收藏数、分区、UP 主、UID、版权、合作视频、合集状态/ID/名称/数量 |
| 章节 | 标题、起止时间、起止秒数、持续秒数、章节图片 URL、章节类型/团队字段 |
| JSON | 上述字段、导出时间、来源与统计、每条记录的 raw 原始接口数据 |

接口未返回的字段会留空；合集状态按接口的 season_id / meta 判断，不能保证覆盖所有合集关系。时间文本使用浏览器本地时区，时间戳可用于进一步转换。封面和章节图仅导出 URL，不下载图片或视频文件。

## 注意事项

- 只能读取当前账号可访问的公开投稿；删除、私有、审核中的内容无法导出。分页结果会去重，但不能保证接口分页漂移时绝不遗漏。
- 分页间等待 650 ms。出现 `-352`、`-412` 或 HTTP 错误时暂停操作，确认登录状态后再试。
- 获取过程中不要刷新页面或切换 UP 主 / 视频；重新导出旧数据前请核对所属 UID。
- 浏览器可能询问是否允许连续下载两个文件；允许后才能同时保存 JSON 和 CSV。
- 脚本复用浏览器登录态向 B 站发送请求，不收集或上传 Cookie，不向作者服务器发送导出结果。依赖 CryptoJS 从 cdnjs 加载，界面图片由 B 站返回的 URL 加载。
- B 站页面、接口、CORS 或扩展环境变化可能影响使用。问题反馈请附页面类型、脚本版本、面板错误信息；不要贴 Cookie。

## 技术原理

1. 从 URL 识别 UID / BV 号和当前分 P。
2. 投稿功能读取 WBI 密钥，使用 CryptoJS MD5 生成签名，再分页查询空间公开投稿。
3. 规范化接口字段、去重，根据合集字段展示筛选列表。
4. 章节功能读取视频详情和播放器信息中的 `view_points`。
5. 用户确认后用 Blob 在浏览器中生成文件，并通过扩展下载接口或浏览器下载保存。
