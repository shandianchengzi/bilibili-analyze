# Bilibili 投稿与视频章节导出

整理 UP 主公开投稿，筛选未加入合集的视频；导出当前视频的分 P、章节 / 看点与现有字幕。

## 功能

① 分页获取公开投稿、去重并预览，默认选择未加入合集的视频。
② 按合集状态筛选、搜索标题、逐条勾选，导出 JSON 和 CSV。
③ 获取后使用“选择并导出”重新选择，无需重复请求。
④ 视频页读取全部分 P 标题，以及当前 P 的章节，复制或导出 JSON / CSV。
⑤ 当前 P 的字幕支持语言选择、预览、复制纯文本以及 SRT / TXT / JSON 下载。

## 使用

登录 B 站，打开 UP 主空间，点击右下角“获取投稿列表”。确认勾选后点击“导出已选视频”。切换筛选不会清除其他筛选下的勾选，请检查已选数量。

打开 BV 视频页，点击“获取章节”，在弹窗中复制或导出。没有提供章节的视频会显示空结果。点击“获取字幕”可选择当前 P 的字幕语言并导出；不对音频做语音识别。

## 注意事项

v1.5.1 修复 AI 字幕 CDN 因 `@connect` 域名不匹配而无法下载的问题。字幕使用不带 Cookie 的浏览器请求；如果仍提示未授权，请在油猴中更新或重新安装并允许访问 `aisubtitle.hdslb.com`。


只支持接口返回的公开投稿与章节，不下载视频。刷新页面后内存缓存消失。接口缺失字段会留空，合集判断以接口返回为准。遇到风控提示请停止请求并稍后重试。

脚本使用当前浏览器登录态，不向作者上传 Cookie 或结果。CryptoJS 依赖从 cdnjs 加载，预览图片按 B 站返回的 URL 加载。
